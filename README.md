# О проекте

Задача на адаптивную верстку с использованием простого html/css/js.

Я стремился выполнить это задание так, чтобы результат выглядел хорошо на всех фиксированных размерах экрана, которые даны на панели разработчика. Тем не менее, при нестандартных размерах экрана, которые в реальности не встречаются, верстка может выглядеть криво.
